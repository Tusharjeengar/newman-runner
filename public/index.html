🧠 How AI Insights works +
• Analyzes all JSON reports in your reports folder automatically.
• Flaky Detection: Identifies tests that flip between pass/fail across runs.
• Anomaly Detection: Uses statistical z-score analysis to flag abnormal response times.
• Failure Classification: Groups failures by root cause (auth, server, timeout, data).
• Health Score: Weighted score (0-100) based on pass rate, flakiness, and anomalies.
• Recommendations: AI-generated action items based on detected patterns.
• Tip: The more reports you have, the better the analysis. Run tests regularly for best results.

🤖 How Assert Generator works +
• Paste a JSON response body from any API endpoint.
• The AI engine analyzes structure, types, patterns (email, UUID, dates, URLs).
• Generates ready-to-use Postman test scripts you can copy directly.
• Depth: Shallow = top-level only. Deep = nested objects too.
• Style: Strict = exact values. Balanced = types + patterns. Flexible = existence only.
• Includes: schema validation, type checks, pattern matching, security checks, null guards.

💾 How Saved Runs work +
• Create a preset with a name, then add multiple run configurations inside it.
• Each run = collection + folder + environment + data file + variables.
• One-click "Run All" executes all runs in the preset sequentially.
• Example: "Regression - Dev" preset with 3 runs: Payment, Refund, Settlement.
• Persists across app restarts (saved locally).

⏰ How Scheduler works +
• Select a collection and check the folders you want to automate.
• Set a time — the job will trigger at that exact date/time.
• Schedule type: "Once" runs one time only. "Daily" repeats every day at the same time. "Hourly" and "Every 30 Min" repeat continuously.
• Multiple folders: If you select 5 folders, all 5 will run sequentially at the scheduled time.
• Reports: Each folder generates its own HTML + JSON report with your job name.
• Requirement: The app must be running for scheduled jobs to execute. If the app is closed, jobs will not run until you reopen it.
• Tip: Add the app to Windows Startup so it's always running when your PC is on.
